立即生成 · 地道俚语

俚语默认来自 Urban Dictionary（可在 .env 的 SLANG_SOURCE 切换为 lemmy / reddit / auto），由 AI 提炼讲解。

批量补历史内容

按日期范围逐天生成，已生成过的日期会自动跳过；俚语会自动避开历史已用过的表达。范围较大会耗时较久。

批量删除历史内容

删除后该范围内内容会重新变为空，可用「批量补历史」重新生成（俚语会避开仍存在的历史词）。

API Key 与定时

系统会在每天这个时间自动生成当天的初中英语和俚语内容。

填写 Reddit 凭证后，俚语模块改用官方 OAuth 接口（更稳定，不易被 403 屏蔽）。申请地址：reddit.com/prefs/apps。
